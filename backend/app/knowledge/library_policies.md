# AI Library Management System — Knowledge Base & Policies

This document serves as the authoritative, verified knowledge base for the AI Library Copilot. All factual statements regarding circulation rules, technical features, and system workflows are grounded in the application's real database schema and service contracts.

---

## 1. Borrowing and Circulation Rules

- **Standard Loan Duration**: 14 calendar days from the date of issuance.
- **Maximum Active Loans**: A student may borrow a maximum of 3 physical books concurrently.
- **Overdue Suspension**: If a student has one or more overdue loans (past their 14-day due date and not yet returned), the system strictly blocks the issuance of any additional books until all overdue items are returned.
- **Return Procedure**: Books cannot be returned online. Physical copies must be presented to library staff at the Circulation Desk, who verify the barcode/copy code and record the return in the system.
- **Renewals**: *Configurable policy* — Online automatic loan renewals are currently not enabled in this release; students must request extensions in person at the Circulation Desk subject to copy reservation demand.
- **Fines and Overdue Penalties**: *Unverified policy* — Monetary overdue fines are campus-specific and not tracked by this automated software. Students should consult their institution's physical library desk for monetary fine policies.

## 2. Using the Catalogue and Search Features

- **Keyword & Metadata Search**:
  - Located on the **Catalogue** tab.
  - Allows searching by title, author, or ISBN-13.
  - Supports filtering by category (e.g., Computer Science, Artificial Intelligence, Cybersecurity, General Technology).
  - Displays real-time availability counts (e.g., `2 / 3 available`) calculated dynamically from active loans and physical maintenance statuses.
- **AI Semantic Search**:
  - Located on the **AI Search** tab.
  - Uses dense 384-dimensional vector embeddings generated by the pretrained `sentence-transformers/all-MiniLM-L6-v2` neural model.
  - Allows conceptual, natural-language queries (e.g., *"distributed fault-tolerant microservices"*, *"neural network backpropagation and attention"*, *"quantum key distribution"*).
  - Calculates cosine similarity against all indexed monographs and ranks the most relevant titles with a similarity score badge.
  - If the PyTorch vector model is offline, the system safely falls back without crashing the standard keyword catalogue search.
- **Content-Based Book Recommendations**:
  - Accessible via the **View Details & Copies** modal on any book card.
  - Uses high-dimensional cosine similarity between catalogued book embeddings to recommend up to 5 conceptually related titles.
  - Automatically excludes archived titles and stale embeddings whose metadata was modified after vector generation.

## 3. Account Roles and Access Permissions

- **Student Role**:
  - Authenticated via secure HttpOnly session cookies.
  - Can browse the public catalogue, perform AI semantic searches, view book details, and see their own personal active and returned loan history under **My Loans**.
  - **Privacy Boundary**: Students cannot view the borrowing history, contact information, or account details of any other student.
- **Librarian Staff Role**:
  - Designated by the `librarian` role badge.
  - Has access to administrative tabs:
    1. **Catalogue Management**: Add new books with ISBN-13 checksum validation; register physical copies with custom barcodes; update book descriptions; soft-archive retired titles.
    2. **Circulation Desk**: Issue loans by entering a student ID and copy code (with atomic transaction locks preventing TOCTOU double-lending); process physical returns; view all active, overdue, and returned circulation records.
    3. **AI Embeddings**: Monitor total catalogued books, missing embeddings, and stale vectors; trigger batch vector generation and model weight cache checks.

---

## 4. Troubleshooting and Physical Desk Procedures

- **Physical Hours & Stack Locations**: Main library stacks and reserve desks are arranged by subject category and copy code. Exact desk operating hours are set by campus administration.
- **Lost or Damaged Copies**: Physical copies marked as `maintenance` or `lost` by librarians are automatically excluded from the available inventory count in the catalogue.
