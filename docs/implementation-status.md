#### Architectural Limitations & Verification Notes for DISC-05:
1. **Bounded Candidate Retrieval:** Candidate pool retrieves top 100 lexical candidates and top 100 semantic candidates (maximum 200 fused candidates).
2. **Candidate-Pool Pagination:** The API response `total` and `total_pages` fields describe the bounded candidate pool ($\le 200$), not the unconstrained database count. Records outside the top 100 of both channels cannot be reached via pagination.
3. **Evaluation Dataset Scope:** Evaluated across 30 benchmark queries grounded in synthetic catalogue monographs from Stages 2–4. Relevance judgments reflect synthetic monograph targets requiring ongoing evaluation against live patron queries.
4. **Empirical Latency Characteristics:** Measured warm query latency (~35ms mean, 53.7ms P95) reflects local single-process development execution, not an SLA commitment. Detailed report: [`docs/stage8-hybrid-search-report.md`](file:///c:/Users/aryan/OneDrive/Desktop/AI-Library-Management-System/docs/stage8-hybrid-search-report.md).
